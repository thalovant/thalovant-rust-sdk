# Shared SDK behavior contract

This acceptance record binds applicable capabilities to reviewed Python reference
digests and the actual implementation/test files in this repository. Required
capabilities have concrete regression evidence; exclusions explain supported
platform boundaries. A changed reference or changed evidence fails the parity
check until the affected behavior has been reviewed, ported, and tested.

The `SDK parity` workflow runs on PRs, main, and every six hours. Release and
publishing jobs depend on it. Normal language CI executes the regression suites;
managed ports also execute shared question and inventory fixtures generated by
the Python SDK. Scheduled runs freshly resolve Python dependencies and verify
those committed expectations.

To check locally with sibling SDK checkouts, run Python 3.11+:

```sh
python ../thalovant-python-sdk/scripts/check-sdk-parity.py --workspace .. --consumer thalovant-rust-sdk
```

A coordinated additive rollout may acknowledge both current and proposed
reference digests. Merge compatible consumers before the producer's full gate.
Never refresh evidence solely to make a failed check green. See the Python SDK's
[contract workflow](https://github.com/thalovant/thalovant-python-sdk/tree/main/contracts)
for regeneration and review responsibilities.
